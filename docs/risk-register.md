# Transition Risk Register

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Knowledge incomplete | Rework / escalation | Peer review and test cases |
| Missing permissions | Fulfilment delay | Access checklist before pilot |
| Volume underestimated | Capacity pressure | Baseline demand and peak periods |
| Hidden exception paths | Failed requests | Pilot representative scenarios |
| Reporting gap | Poor control after go-live | Define KPIs before transition |
| Ownership unclear | Requests stall | RACI and named service owner |
| Premature handover | Increased incidents | Acceptance gate and hypercare |
