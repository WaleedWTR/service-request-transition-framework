# Transition Framework

## 1. Discover

Understand:

- request types and demand
- fulfilment steps
- resolver dependencies
- tooling and permissions
- knowledge requirements
- failure / escalation paths

## 2. Baseline

Capture:

- volume
- cycle time
- SLA achievement
- first-time-right rate
- reassignments
- avoidable escalations
- customer contacts

## 3. Design

Define the target:

- owner
- resolver group
- fulfilment steps
- permissions
- knowledge article
- automation opportunity
- escalation route

## 4. Readiness

Confirm:

- access is available
- knowledge is approved
- training is complete
- test requests have passed
- reporting is available
- support/escalation paths are understood

## 5. Pilot and acceptance

Use a controlled sample before full transition. Record exceptions rather than treating them as informal tribal knowledge.

## 6. Hypercare

Track early:

- rejects
- reassignments
- SLA misses
- knowledge gaps
- customer contacts
- repeat questions

## 7. Continual improvement

Review the request catalogue periodically and automate or retire low-value manual steps where justified.
